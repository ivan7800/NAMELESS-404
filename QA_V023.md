## Pruebas ejecutadas en el entorno

- `npm run build:offline` — PASS: archivos independientes `dist/index.html`, `dist/bundle.js`, `dist/style.css`.
- `node --check dist/bundle.js` — PASS: sintaxis JavaScript del bundle.
- `npm run test:all` — PASS: batería de pruebas anterior (155 pruebas de regresión reportadas en v0.22; cubre campaña, terror, sigilo, puzles, rutas, iluminación y renderizadores a nivel estructural).
- `python tests/browser023.py` — PASS Chromium de escritorio y móvil **emulado**: consola modo libro con dos lienzos 192×256, RPG horizontal con dos lienzos 256×192, cambio entre mundos, imágenes renderizadas en ambos lienzos, controles, ausencia de errores JS.
- `python tests/browser023gpu.py` — PASS WebGL2 con **API simulado**, shaders aceptados por el mock, comandos gráficos recibidos y uniforme `u_resolution=[384,256]`.
- `INICIAR-LINUX.sh --check` — comprobación de archivos y entorno; el juego sigue usando servidor HTTP local de Python3.
