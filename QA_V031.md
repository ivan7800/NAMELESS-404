## Restricciones y riesgos no resueltos

- **No se ha validado WebGL2 nativo ni Three.js en GPU física.** Se han conectado las mismas variables `cameraYaw`, `cameraPitch` y `cameraHeight` a ambos renderizadores y pasado pruebas estructurales, pero falta inspección de la imagen real, GLSL compilado por GPU y rendimiento.
- `npm run typecheck:three` continúa bloqueado por el módulo npm `three` no disponible en este entorno; debe ejecutarse con dependencias instaladas.
- **No existen todavía desplazamiento físico libre, colisiones continuas ni mouse-look completo de 360°.** La cámara visual permite observar un ángulo limitado de ±39° y ±14°; el motor sigue girando en pasos de 90° y moviéndose por casillas. Se ha elegido esta separación para no romper los siete capítulos.
- La persistencia de `localStorage`, la compatibilidad de mando físico, la ergonomía táctil en teléfonos reales, los FPS y el audio con auriculares necesitan validación en Linux Mint/Windows reales.
- No hay evaluación humana suficiente para asignar un 9,5/10.

## Reproducción

```bash
npm run typecheck
npm run build:offline
node --check dist/bundle.js
npm run test:all
python3 tests/camera-browser031.py
./INICIAR-LINUX.sh --check
./INICIAR-LINUX.sh
```

En Linux Mint abre `http://127.0.0.1:8765/`, verifica la etiqueta **V 0.31.0 CINEMATIC CAMERA**, arrastra el dedo o ratón sobre las pantallas en modo libro y prueba los botones «Mirar» y «Centrar vista». Usa «Diagnóstico gráfico» para ver el backend empleado. Antes de evaluar gráficos 3D, verifica que no esté usando Canvas 2D.
