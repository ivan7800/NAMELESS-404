**Fecha:** 29 de octubre de 2026.

## Evidencia ejecutada

- `npm run test:all`: PASS, **172 verificaciones** en conjunto (155 de la versión previa + 17 de `rooms024.test.mjs`). La primera parte cubre los siete días, los tres finales y los sistemas premium anteriores; la nueva parte cubre el mobiliario y la integración.
- `npm run build:offline` + `node --check dist/bundle.js`: PASS. Durante el desarrollo se detectó y corrigió un nombre de constante duplicado al juntar módulos en un único script; la versión empaquetada no contiene ese fallo.
- `python tests/browser024.py`: PASS Chromium escritorio 1440×1024 y móvil emulado 393×852. Inicio, pantalla doble en modo libro, cambio RPG, retorno, vista de recepción y ningún error JavaScript. **Canvas 2D de compatibilidad**, no GPU real.
- `python tests/browser023gpu.py`: PASS con WebGL2 **simulado**, órdenes de dibujo y uniforms 384×256 comprobados. El mock no compila GLSL real.
- `./INICIAR-LINUX.sh --check`: PASS y petición HTTP local a `index.html`, `bundle.js` y `style.css`: las tres responden 200.
- SHA-256 `src/engine.ts` idéntico a v0.23: `e20e0b66304bceafe4e2c50cb3db2c4fbd649602b507cb22192e29a169277fd0`.

## Limitaciones abiertas

- No hay contexto WebGL2 real en el Chromium del entorno, tampoco con renderización SwiftShader forzada. No se validan los píxeles reales del shader ni el rendimiento GPU.
- `npm run typecheck:three` no puede completarse sin instalar `three`/`@types/three`: TS2307. El código opcional se ha integrado, pero **no se da por probado**.
- No hay prueba real de persistencia tras reiniciar navegador en Linux Mint del usuario, ni test de mando físico.
- No hay playtest humano de terror, sonido o duración, ni rendimiento medido con hardware del usuario.
- Los 117 prismas mejoran la lectura espacial, pero no sustituyen modelos 3D artísticamente terminados.

## Reproducir localmente

```bash
npm run test:all
python3 tests/browser024.py
python3 tests/browser023gpu.py
./INICIAR-LINUX.sh --check
```

Para probar la opción de Three.js en un ordenador con acceso a npm: `npm install && npm run typecheck:three && npm run dev`. Para el juego offline no se necesitan dependencias: `./INICIAR-LINUX.sh`.
