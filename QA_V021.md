# NAMELESS 404 Premium 0.21 — Auditoría de render y evidencia QA

**Fecha:** 29 de octubre de 2026. **Alcance:** Día 1, dirección visual; protección de regresión Días 1–7 y tres finales.

## Cambios y riesgos reales

- Nuevo módulo `src/premium/KibaVisuals.ts`: escena compartida con señalización física, agua estancada, luminarias, cables, cuadros de pintura, juntas de suelo y siete marcas de lugar. Los objetos no modifican mapas, colisiones ni guardados.
- WebGL2 nativo: la geometría se incorpora al buffer estático del nivel. Shader fragment con iluminación periférica, gradación de profundidad y grano reducido a 256 × 192. El render 3D completo sigue **sin validación gráfica en GPU física**.
- Three.js opcional: reutiliza la misma geometría agrupada por materiales con `InstancedMesh`, sin un `Mesh` por objeto decorativo. Sin embargo, `three` no está disponible en este entorno y la compilación de esa variante no se ha completado.
- Diagnóstico manual: `src/premium/GPUDiagnostics.ts` dibuja un cuadrado con shader ES 3.00 en un lienzo 16×16 y consulta el píxel central. Es independiente de Three.js y no equivale a probar toda la escena 3D.
- Corrección importante: se detectó una colisión de nombre en el bundle autónomo (`hash` global duplicado) que lo impedía arrancar. Resuelto renombrando el helper y añadiendo `node --check dist/bundle.js` a la batería oficial.

## Reproducción

```sh
npm run test:all
python3 tests/browser021.py
./INICIAR-LINUX.sh --check
./INICIAR-LINUX.sh
```

En el juego abre **«Diagnóstico gráfico»**. Si la máquina dispone de WebGL2, el autotest debería mostrar `shader PASS · píxel PASS`. Para confirmar el motor 3D revisa además el campo **MOTOR GRÁFICO**, que debe decir `WEBGL2 NATIVO`, no `CANVAS 2D`. El estado del autotest no valida rendimiento ni garantiza la calidad de la escena.

Para Three.js en un equipo con acceso al registro npm:

```sh
npm install
npm run typecheck:three
npm run build
npm run dev
```

En la variante de desarrollo confirma el indicador `THREE.JS / WEBGL2`, los fotogramas en una GPU real y la ausencia de errores en consola. En este entorno no se ha podido ejecutar esa secuencia completa.
