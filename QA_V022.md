## Auditoría y defecto real corregido

En `src/gfx/RetroWebGL.ts` de v0.21, el shader de fragmento contenía **dos declaraciones locales de `float grain`** y utilizaba `u_resolution` sin declarar ese uniforme dentro de GLSL. Ambas circunstancias impiden una compilación GLSL ES 3.00 conforme a especificación. Al no poder compilarse, el constructor del backend nativo puede devolver `null` y activar Canvas 2D, incluso en dispositivos compatibles. Los tests de la v0.21 solo observaban la entrega del shader a un mock, que **aceptaba cualquier texto sin compilarlo**.

**v0.22:** nombres separados `surfaceGrain` y `filmGrain`; declaración de `uniform vec2 u_resolution;`; materiales con detalle de superficie; iluminación puntual anclada a tres fuentes cercanas; tono de la linterna, grano de pantalla y niebla. El diagnóstico gráfico ofrece, cuando está activo WebGL2 nativo, una lectura real con `gl.readPixels` y revisión de `gl.getError()` del framebuffer del juego. Se mantienen las rutas Canvas 2D y Three.js.

1. **Shader GLSL ES 3.00 en hardware:** el Chromium disponible no expone un contexto WebGL2 ni con SwiftShader. La revisión de declaraciones y el mock aportan prevención, pero no equivalen a una compilación en GPU. Realizar diagnóstico en Linux Mint y Windows.
2. **Three.js real:** no es posible instalar `three` desde el registro npm en este entorno. No se ha comprobado la compilación ni el rendimiento Three.js real con las nuevas `PointLight`.

## Reproducción en Linux Mint

```sh
chmod +x INICIAR-LINUX.sh
./INICIAR-LINUX.sh --check
./INICIAR-LINUX.sh
```

En el navegador abre **Diagnóstico gráfico**. Si el motor indica **WEBGL2 NATIVO**, y los dos indicadores de diagnóstico dicen `shader PASS · píxel PASS` y `Lectura framebuffer WebGL2: PASS`, el shader del juego se ha podido crear y el framebuffer se ha leído sin error GL en **ese dispositivo**. Un `CANVAS 2D` indica que se usa la ruta de respaldo, no necesariamente un fallo del juego.

Para repetir las pruebas desde el ZIP con Node.js y TypeScript disponibles:

```sh
npm run test:all
python3 tests/browser022.py
```

Para la variante Three.js (solo en equipo con red para instalar dependencias):

```sh
npm install
npm run typecheck:three
npm run build
npm run dev
```

**Conclusión:** la v0.22 resuelve un error real del shader y aporta iluminación local con pruebas de no regresión. **No certifica todavía 9,5/10 ni garantiza funcionamiento WebGL2 sin validación física.**
